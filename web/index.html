Superpowers

Built for Windows. Powered by SOTA AI.

No browser sandbox limitations. Zuki operates natively with real Windows UI Automation and Win32 controls.

👁️

Pixel-Accurate UI Snapping

Unlike raw vision guesses, Zuki inspects the Windows UI Automation (UIA) tree to snap directly onto native buttons, text inputs, and menus with 100% click fidelity.

⚡

Groq & Deepgram Voice

Push-to-talk with streaming STT powered by Deepgram or Groq Whisper-large-v3, responding in sub-seconds with realistic Edge-TTS narration.

🦾

Hands-On Computer Use

Direct actuation via Claude Computer Use. Zuki navigates apps, types text, and finishes tasks, guarded by an emergency Esc abort key.

🗂️

Journaled File Organizer

Tidies cluttered Desktops and Downloads with single-step LLM classification. Every operation is journaled and 100% reversible via zuki undo.

📦

Background Hermes Agents

"Go research X and report back." Background agents run asynchronously with DDGS search, delivering real files and syncing with connected Notion/Composio MCP tools.

🧠

Learned Voice Skills

Teach Zuki custom routines simply by voice: "Save this as my morning routine". Skills are saved as open, PR-able SKILL.md files.
