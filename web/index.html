Engineering Architecture

How Zuki operates your desktop

A purpose-built hybrid client uniting ultra-fast local Windows hooks with frontier multimodal models.

01

Hotkey & Audio Stream

Global keyboard listener catches Ctrl+Shift+Space or microphone activity. Raw 16kHz audio streams to Groq's Whisper LPU for near-instant transcription in under 200ms.

02

Visual & UIA Parsing

Zuki grabs high-res desktop screenshots through DXGI and simultaneously inspects the Windows UI Automation tree to identify clickable buttons, active inputs, and window hierarchies.

03

Computer-Use Execution

Claude 3.5 Sonnet computer-use calculates the exact coordinate trajectory, issuing safe mouse moves, clicks, keyboard typing, and file operations with continuous visual feedback.

Frequently Asked Questions

Which versions of Windows are supported?

Zuki is built natively for 64-bit Windows 10 and Windows 11 with full support for the modern Windows UI Automation API.

Is my screen recorded or sent to third parties?

Never without your command. Screenshots are only taken when you trigger a request. Data is processed directly with your API credentials or encrypted through your private proxy.

How do I cancel actions if Zuki does something unexpected?

You can tap the Esc key 3 times at any moment to trigger an immediate hardware interrupt that freezes all mouse and keyboard actions.
