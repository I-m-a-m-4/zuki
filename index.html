Engineering Architecture

How Zuki operates your Windows desktop

A high-performance Windows client uniting ultra-fast local OS hooks with frontier multimodal AI.

01

Hotkey & Audio Stream

Global keyboard listener catches Ctrl+Shift+Space. Raw 16kHz audio streams to Groq's Whisper LPU for near-instant transcription in under 200ms.

02

Visual & UIA Parsing

Zuki grabs high-res desktop screenshots through DXGI and simultaneously queries the Windows UI Automation tree to identify clickable buttons, active inputs, and window hierarchies.

03

Computer-Use Execution

Claude 3.5 Sonnet computer-use calculates the exact coordinate trajectory, issuing safe mouse moves, clicks, keyboard typing, and file operations with continuous visual feedback.

Frequently Asked Questions

Why is Zuki exclusively available on Microsoft Store?

Distributing through the Microsoft Store ensures that every release is digitally signed, sandboxed, and verified for security. It provides smooth auto-updates and full access to the Windows UI Automation APIs.

Which versions of Windows are supported?

Zuki is built natively for 64-bit Windows 10 and Windows 11 with full support for pywinauto and the modern Windows UI Automation tree.

Is my screen recorded or sent to third parties?

Never without your explicit voice command or prompt. Screenshots are only taken when you initiate an action, and memory remains strictly on your local disk.
